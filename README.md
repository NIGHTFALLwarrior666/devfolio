# DevFolio — Abishek S J

A responsive personal developer portfolio for Kalvium's **Project 2.4: DevFolio — Build & Deploy Your Portfolio**.

## Live portfolio

- [Live website on Vercel](https://devfolio-abishek-preview-nightfallwarrior666.vercel.app)
- [Source repository](https://github.com/NIGHTFALLwarrior666/devfolio)
- GitHub Pages URL (after enabling Pages in repository settings): https://nightfallwarrior666.github.io/devfolio/

## Features

- Semantic `header`, `main`, `section#about`, `section#projects`, and `footer#contact`
- Accessible responsive header navigation
- Defined CSS colour and typography system
- Flexbox and CSS Grid layouts
- Multiple responsive media-query breakpoints
- Responsive image styling
- Real bio, project cards, and GitHub/LinkedIn/Contra contact links
- Small UI enhancements and reduced-motion support

## Run locally

Open `index.html` in any modern browser. All portfolio styling and scripts are inlined so the website needs no build step.

## Deploy with GitHub Pages

Repository **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**.

## Submission

Submit the URL of the open **DevFolio submission** pull request, not the GitHub repository homepage.
